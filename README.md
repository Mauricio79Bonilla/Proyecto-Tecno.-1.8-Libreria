# BOOKY

Sistema de gestión de bibliotecas y recursos del Instituto Nacional San Luis.

## Instalación

1. Copia `config.example.php` como `config.php` y completa los datos de tu base MySQL.
2. Ejecuta `base-de-datos.sql` en tu base de datos.
3. Agrega `LIBROS.jpeg` y `banner.png` en la misma carpeta que `index.html`.
4. Sube todo a un servidor con PHP y MySQL, o a `htdocs` en XAMPP, y abre `index.html` desde `http://localhost/`.
